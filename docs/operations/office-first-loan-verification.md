## Cross-cutting checks

- Role and device checks apply both at protected API boundaries and persisted repository authorities. Collector and Client roles cannot perform office approval or release even if a permission is accidentally assigned.
- Protected evidence checks exact actor, Client, purpose, subject and snapshot, then verifies stored byte count and hash. A typed reference alone cannot confirm a new review or contract.
- Clear, changed selection, logout, remount and late responses are covered by the office selection, correction, application, evidence and first-loan tests. Uncertain writes require saved-state reconciliation; account recovery does not repeat release.
- Existing Area and office panels coexist: [CIF/Area integration](../../spina_portal/tests/office-cif-area-coexistence.test.mjs), [first-loan workspace](../../spina_portal/tests/office-first-loan-workspace.test.mjs). API responses remain private and are excluded from service-worker caching.
- Shared-loan compatibility is covered by the first-loan PostgreSQL guards and [unreleased disbursement readiness](../../gilbic_backend/tests/test_unreleased_disbursement_readiness_api.py). Generic schedule/disbursement mutation cannot activate an unreleased first loan; a committed release event cannot be independently voided.

### PDF dependency correction

Fresh PyPI advisory metadata identified published resource-exhaustion and infinite-loop fixes missing from the newly introduced pypdf 6.10.0 pin. Both dependency declarations now pin **6.16.1**, which includes the maintainers' [iteration-limit fixes](https://github.com/py-pdf/pypdf/releases/tag/6.16.1) and follows the [affected-version advisory](https://github.com/py-pdf/pypdf/security/advisories/GHSA-jp53-mhqp-8xcg). The eight installed packages in the new PDF dependency closure had no listed advisories when checked on 2026-09-19; this is a dated package check, not a claim that the whole application is vulnerability-free. With the patched parser, **106 document/evidence/Annex/font tests passed**, and the six real converter cases passed with unchanged pagination and exact installment rows. Normalized visible text matched the previous output, and all 18 filled form pages were pixel-identical. Final acceptance still requires the matching published-head CI results.
